# creatives

An experimental playground. Things here are tries, prototypes and ideas — nothing is guaranteed to be stable or finished.

## Rules

- **No pull requests.** Do not open PRs against this repo. Any PR will be closed without review.
- **Work in branches.** Every experiment lives on its own branch and stays there.
- **Name branches for what they do.** The name should say what the experiment is, e.g. `soundmesh-bluetooth-fanout`, `gif-to-ascii-renderer`, `try-webgpu-particles`. Avoid vague names like `test`, `wip`, `fix` or `my-branch`.
- `main` holds only this README and things deliberately promoted from experiments.
