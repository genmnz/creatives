What the file says

The rules an AI needs, and how sure each one is. The full write-up is spec/FORMAT.md.

Layers are listed back to front

seen in app files

<shape>, <text>, <drawing>, <embedScene>, <nullobj>, <audio> inside <scene>. Times are integer milliseconds.

Keyframe t is a fraction of the layer

seen in app files

t="0.3" on a 4 s layer means 1.2 s in. The community docs say seconds; all 615 keyframes in the app's files are between −0.017 and 1.003.

Easing sits on the keyframe it eases into

seen in app files

e="cubicBezier 0.42 0.0 0.58 1.0"; no e means linear.

Template size is half the width and height

seen in app files

A full-frame rectangle on a 1080 canvas is size="540,540".

Custom shapes are SVG paths

seen in app files

<path d="M … L … C … Z"/> relative to the layer's position, absolute commands only. The toolkit converts any SVG path.

Strokes are <path-stroke>

seen in app files

With <color> and <size> children, so both can be animated.

A photo is a rectangle with a media fill

seen in app files

fillType="media" fillImage="am-internal:///<sig>.jpg", declared once in a <media> entry.

Effects are referenced by full id

seen in app files

com.alightcreative.effects.gaussianblur with <property> parameters. All 282 are in the catalog with exact names and ranges.

Nested scenes, parenting, freehand strokes

from decompile

<embedScene>, parent="id", <stroke points="x,y,p;…">.

Zip package layout

untested

XML plus media files named by their SHA-1, mirroring the app's “Share Zipped XML”. A bare XML import works with media marked missing.

Give it to an AI

Three ways in, from most to least capable.

MCP server

For Claude Desktop, Claude Code or any MCP client. The model builds from a design spec, edits with operations, looks at rendered PNG frames, and exports the XML.

claude mcp add alight-motion -- \
  node creatives/alight-motion-ai/mcp/server.mjs

Tools: am_guide, am_build, am_edit, am_render, am_export, am_effects, am_effect, am_open …

Command line

For an AI with a shell, or for you. No dependencies beyond Node.

node bin/amx.mjs build design.json --png
node bin/amx.mjs inspect project.xml
node bin/amx.mjs effects glow

Prompt only

Paste SYSTEM_PROMPT.md into any chat model's instructions and ask for XML. It holds the rules, a worked example and the 28 most useful effects with their parameters.

What still needs your phone

Running Alight Motion in an emulator was not possible here: the build machine has no hardware virtualization, and the APK and Android SDK downloads were blocked. Everything above is checked against the app's own files, but nothing has been imported into the app yet.

  1. Import examples/out/01-text.xml. If it opens, the core format is confirmed.
  2. Import 02-images.zip, then 02-images.xml on its own. This settles how images travel.
  3. Import 06-keyframes.xml and check the star spins once over 4 seconds. This confirms keyframe timing.

Each sample's XML is one tap away in the viewer's XML tab. All files are on the branch, in examples/out/.
